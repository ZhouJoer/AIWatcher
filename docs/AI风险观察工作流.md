# AI风险观察工作流

这个工作流用于定期观察 AI 是否从真实建设进入泡沫反噬阶段。核心思想是：先看应用端现金流，再看模型经济性，然后看云资本开支、GPU、数据中心、电力和融资市场是否同步恶化。

## 文件结构

- `data/ai_risk_metrics.json`：指标快照、分数、趋势、危险信号和建议数据源。
- `tools/ai_risk_dashboard.py`：读取指标快照，计算分层风险和总风险。
- `output/ai_risk_dashboard.html`：可视化仪表盘。
- `output/ai_risk_dashboard.md`：Markdown版仪表盘，方便复制、归档和二次加工。
- `output/pdf/AI泡沫观察指标手册.pdf`：长期观察手册。

## 每次更新步骤

1. 更新 `data/ai_risk_metrics.json`：
   - `metadata.as_of` 改成数据日期。
   - 每个指标更新 `score`、`trend`、`current_read`。
   - 如果出现新风险，补充 `watch_signals`。
2. 运行：

```powershell
python .\tools\ai_risk_dashboard.py
```

3. 打开 `output/ai_risk_dashboard.html` 查看仪表盘。
4. 如果总风险升到红灯，或应用端、云资本开支、GPU 三层同时恶化，写一份单独复盘。

## 评分规则

- 0-39：绿灯，风险低。
- 40-59：黄灯，需要观察。
- 60-74：橙灯，风险偏高。
- 75-100：红灯，需要重点警惕。

分数越高，泡沫化和回撤风险越高。分数不是精确预测，而是为了让风险变化可比较。

## 优先观察顺序

1. 应用端 ROI：续费率、席位扩张、AI 独立付费、企业预算转化。
2. 模型经济性：ARR、毛利率、API 价格、推理成本、现金消耗。
3. 云与资本开支：capex/revenue、自由现金流、折旧、capex 指引。
4. GPU 与半导体：交付周期、租赁价格、库存、Nvidia 数据中心收入。
5. 数据中心与电力：上电、空置率、PPA、项目取消、融资成本。
6. 融资与私募估值：估值/收入倍数、二级折价、结构化条款、GPU 抵押融资。
7. 市场集中度：Mag 7 权重、市场宽度、AI 链条相关性。
8. 竞争与商品化：开源模型、小模型、价格战、模型切换成本。
9. 宏观流动性：利率、信用利差、美元、金融条件。
10. 监管与法律：版权、隐私、反垄断、出口管制。

## 红色预警组合

最强预警组合是：

企业 ROI 不清 + 模型 API 价格战 + 云 capex 下调 + GPU 租赁价格下跌 + Nvidia 或上游订单放缓。

这个组合出现时，应把 AI 从成长故事重新定价为资本开支过剩故事。

## 建议节奏

- 每周：看市场集中度、AI 链条股价、GPU 租赁价格、项目取消和融资失败新闻。
- 每月：更新 API 价格、云 GPU 报价、私募融资、数据中心租赁和开源模型进展。
- 每季：完整更新财报指标，重点看 Microsoft、Amazon、Alphabet、Meta、Nvidia、Broadcom、TSMC、Oracle。
- 每半年：更新企业 AI 调查和生产率证据，判断 AI 是否进入组织级利润兑现阶段。
