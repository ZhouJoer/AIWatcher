# AI风险基准评估 - 2026-06-08

## 基准结论

当前 AI 风险基准定为：**67.8 / 100，橙灯偏高**。

这不是“AI 技术要失败”的判断，而是“资产价格和资本开支已经提前计入很高兑现率”的判断。AI 长期真实，但短中期风险主要集中在三处：云资本开支、私募估值、市场集中度。

## 当前最值得注意的风险点

1. **云资本开支已经过热**  
   Microsoft、Alphabet、Amazon、Meta 的 2026 capex 指引合计约 7000 亿美元以上。只要云收入、AI 收入和自由现金流跟不上，市场会重新定价。

2. **应用端 ROI 尚未普遍兑现**  
   企业使用率高，但组织级财务影响还不稳定。真正要观察续费率、席位扩张、AI attach rate 和可审计 ROI。

3. **上游 GPU 需求仍强，暂未出现铲子失速**  
   Nvidia 最新季度收入和数据中心收入仍大幅增长，所以当前不是“铲子卖不动”的基准，而是“铲子卖得太好，市场押注未来一直这么好”的基准。

4. **私募估值和融资结构风险上升**  
   前沿模型公司的估值已高度依赖远期增长、毛利改善和持续融资。若二级折价扩大或结构化融资变多，是重要预警。

5. **市场集中度本身成为系统性风险**  
   Mag 7 和 AI 链条权重过高，即使基本面只是降温，也可能引发指数层面的明显回撤。

## 触发升级到红灯的条件

若出现以下组合，应把总风险上调到 75 以上：

企业 ROI 不清 + 模型 API 价格战 + 云 capex 下调 + GPU 租赁价格下跌 + Nvidia 或上游订单放缓。

## 触发降级到黄灯的条件

若出现以下组合，可把总风险降到 60 以下：

企业续费强 + AI 独立付费成功 + 云收入加速 + capex/revenue 下降 + 自由现金流稳定 + GPU 利用率高但租价不再失控。

## 后续比较口径

以后每周巡检都与本基准比较：

- 总风险是否高于 67.8。
- 云与资本开支是否继续红灯。
- 应用端 ROI 是否从黄灯转橙灯或红灯。
- GPU 与半导体是否从黄灯转橙灯。
- 是否出现“capex 下调但需求不足”的措辞。
- 是否出现私募二级大幅折价、结构化融资增多、模型公司裁员或低价并购。
